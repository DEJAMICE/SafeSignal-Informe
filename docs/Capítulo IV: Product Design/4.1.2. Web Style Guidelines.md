### 4.1.2 Web Style Guidelines
**Layout y Grid:**
- Usar un sistema de grid para alinear elementos en paneles de administración web o vistas de escritorio.
- Ancho máximo para el contenido principal: 1140px.
- Columnas de grid: 12 columnas con gutters (medianiles) de 24px.
- El diseño web debe seguir un enfoque Mobile-First, garantizando que los elementos críticos se adapten perfectamente a las pantallas de los celulares antes de escalar a escritorio.

**Formularios y Campos de Entrada:**
- Altura de los campos de entrada: 48px (ligeramente más amplios que el estándar para garantizar un área de toque fácil desde cualquier dispositivo).
- Bordes de 1px sólidos y de alto contraste, con un radio de borde (border-radius) de 6px.
- Estados de focus muy marcados para facilitar la configuración rápida de contactos de confianza o el registro de dispositivos IoT.

**Botones:**
- Altura de botones: 44px a 56px (priorizando la accesibilidad táctil para funciones críticas).
- Botones primarios con esquinas redondeadas y sombra sutil para el call-to-action principal (por ejemplo: "Iniciar Modo Seguimiento" o "Sincronizar Sensor Inteligente").
- Se reserva el color Rojo SecuraNet (#D32F2F) exclusivamente para botones de alerta o cancelación de emergencia.

**Tablas y Mapas (Visualización de Datos):**
- Zebra Striping para filas alternadas en la visualización del "Historial de Alertas" o la lista de "Contactos de Confianza".
- Hover state para filas con un cambio sutil de color de fondo.
- Componente de Mapa (IA): Los mapas interactivos de zonas de riesgo no deben tener bordes superpuestos (diseño edge-to-edge) para maximizar la visibilidad de las rutas seguras y los indicadores de peligro.

**Navegación y Menús:**
- Menú lateral colapsable con iconos claros (ej. escudos, pines de ubicación, engranajes) y texto explicativo.
- Barra de navegación superior para información del usuario, acciones rápidas y un indicador siempre visible del estado de conexión Bluetooth del botón de pánico IoT.

**Responsividad:**
- Puntos de quiebre (breakpoints) estándar para dispositivos móviles, tabletas y escritorio.
- Menús adaptables (menú hamburguesa para vistas móviles, barra lateral para pantallas más grandes).

**Accesibilidad:**
- Contraste estricto y adecuado entre el texto y el fondo, especialmente crítico para mantener la legibilidad en el "Modo Oscuro" mientras el usuario camina por calles poco iluminadas.
- Tamaños de texto que soportan zoom sin romper el layout para mejorar la lectura.
- Etiquetas accesibles (aria-labels) para todos los formularios, mapas y elementos interactivos para garantizar compatibilidad con lectores de pantalla.
